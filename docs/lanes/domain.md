# Lane DOM: pure genealogy domain library

> Last Updated: 2026-10-01

Lane DOM builds `family_history.domain`: the pure (no I/O, stdlib-only) semantic core that the
API, the GEDCOM engine and the UI rely on.

## Status

In progress. Modules land in this order: `dates`, `names`, `living`, `events`, `sensitivity`,
`kinship`, `compadrazgo`, `synth`. This file is rewritten with the full public API, design
decisions, test coverage and contract requests when the lane is done.
