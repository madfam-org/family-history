# Lane notes

> Last Updated: 2026-10-01

During the initial build, parallel lanes write their working notes here, one file per lane
(`docs/lanes/<lane>.md`). Shared entry points (README, AGENTS, llms files, ARCHITECTURE) are
consolidated by the coordinator, so lanes never edit them directly. Notes describe what was
built, how it was verified and what is left; they are folded into the canonical docs at
close-out.
