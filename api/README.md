# family-history API

Python 3.12 service for family-history: the FastAPI API, the Celery worker, Alembic migrations,
the MCP server and the pure genealogy library (`family_history.domain`, `family_history.gedcom`).
Contracts are in `../docs/ARCHITECTURE.md`; agent instructions in `../AGENTS.md`.
