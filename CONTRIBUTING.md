# Contributing

> Boundary checkpoint (2026-10-01): public guide. Operational detail stays out of this repository
> per the repo-boundary contract.

Thank you for helping families keep their memory. Before you open a pull request:

1. **Read [AGENTS.md](./AGENTS.md)** for the doctrines and the interface contracts.
2. **Use synthetic data only.** Never add a real person, family, photo, document, CURP or RFC.
   Tests and fixtures come from the synthetic generator.
3. **Keep the language rules.** Code and engineering docs are in English. Everything a family
   reads is Spanish-first, with an English translation.
4. **Run the checks** that apply to what you changed (see AGENTS.md "Working here"). Keep every
   source file under 600 lines.
5. **One concern per pull request,** with a clear English title and a body that says why.

**Licence.** Contributions are accepted under the project licence (AGPL-3.0-only): inbound equals
outbound.
